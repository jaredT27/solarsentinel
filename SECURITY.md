# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Solar Sentinel, please report it responsibly.

**Email:** jared@localmotionai.com
**Subject:** `[SECURITY] Vulnerability Report`
**Response SLA:** Within 24 hours

Please do NOT open a public GitHub issue for security vulnerabilities.

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |

## Security Practices

- All data encrypted in transit (TLS 1.3) and at rest (AES-256)
- Documents auto-deleted within 30 days of report delivery
- Customer data never used for model training
- Mutual NDA available for all engagements
- SOC 2 Type I in progress (target Q4 2026)
